Despliegue reproducible

Bicep define los recursos. GitHub Actions valida el código y construye el contenedor.

Operación y coste

Azure Monitor registra las ejecuciones. La web y el procesador pueden reducirse a cero instancias.

Decisiones y límites del proyecto

Las consultas SQL utilizan DuckDB dentro de la API. Los archivos y estados se conservan en Blob Storage. No se ha desplegado Azure SQL ni Data Factory. El volumen está acotado para una demo de estudiante; los archivos propios se prueban localmente. Una versión empresarial necesita autenticación de usuarios, políticas de retención y pruebas de carga según sus requisitos.
